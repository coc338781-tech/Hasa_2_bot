ADD A LINUX / ORACLE SERVER

Connect another server to your network

You need a Linux server you control (for example, an Oracle Cloud VM). It must have a public HTTPS route to this control-plane API, Node.js 22+, SSH access and enough free RAM. This console does not rent or create cloud servers for you.

To look for a no-cost VM, check Oracle Cloud Free Tier. Oracle lists Always Free AMD micro VMs (1 GB RAM) and Ampere A1 resources (up to 2 OCPUs / 12 GB RAM total, subject to tenancy limits and capacity). Use only shapes explicitly marked Always Free. See the official Linux VM setup guide.

  1. Click Generate one-time ticket above and keep the ticket secret. It expires in 10 minutes.
  2. SSH into the new Linux VM. First authorize read-only access to the private GitHub repository using an SSH deploy key or GitHub CLI login; then run git clone -b feature/hasa-bot-network-foundation git@github.com:coc338781-tech/Hasa_2_bot.git and enter the repository directory. Never put a personal access token in the clone URL. Do not copy your production WhatsApp auth_info folder.
  3. Run the telemetry agent installer: cd network/agent && sudo bash install-systemd.sh.
  4. Edit /etc/hasa-agent/agent.env with sudo nano /etc/hasa-agent/agent.env: set the real HTTPS API URL and paste the one-time ticket. Start it with sudo systemctl enable --now hasa-agent. Once enrolled, remove the ticket from that file and restart the service.
  5. Confirm the new server appears as online here and its RAM / disk values are updating.
  6. Prepare and mount an encrypted volume at /var/lib/hasa-worker/sessions. Install the separate worker only after verifying encryption: cd network/worker && sudo env HASA_CONFIRM_ENCRYPTED_VOLUME=true bash install-systemd.sh. Start it with sudo systemctl enable --now hasa-worker. Wait until the Worker column in this console says online and its session count is updating.
  7. When the worker is healthy, choose the customer bot under Assign bots to online servers and select this server. Only the owner can do this.

Never paste SSH private keys, enrollment tickets, agent tokens, pairing codes or WhatsApp session files into this website or a chat. Do not enrol the production bot's existing auth_info directory as a customer instance.
