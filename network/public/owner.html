AGENT INSTALLATION

Connect an approved Linux server

After generating a ticket, install the agent from the private development branch. Never paste the ticket into chat or a public terminal recording.

cd network/agent && sudo bash install-systemd.sh

Then edit /etc/hasa-agent/agent.env with the HTTPS API URL and one-time ticket, and run systemctl enable --now hasa-agent. Remove the ticket line after enrollment. After the server is online, mount an encrypted filesystem at /var/lib/hasa-worker/sessions and install the separate worker with: cd network/worker && sudo bash install-systemd.sh. The worker token is kept in a root-managed service file; the dashboard never receives it.
